Personal project

FoodTrack

Food-tracking app · React Native

Work in progress

A food-tracking app I have been developing as a personal side project. It is separate from my professional work experience and is still a work in progress.

Users log Morning, Afternoon, and Night meals on a calendar. Their data lives in Google Sheets and is served to the app through a Google Apps Script API.

Working today

  • User flow

    Home, Calendar, Summary, and Profile tabs.

  • User authentication

    Sign in with a username or email and password, checked by the API.

  • Create account

    Sign up in the app. Duplicate usernames and emails are rejected.

  • Persistent sessions

    Users stay signed in between app launches.

  • Calendar-based tracking

    A monthly calendar marks each day as full, partial, or none.

  • Morning, Afternoon & Night

    Meals are tracked per slot, and today’s choices are saved to the sheet.

  • User-specific food data

    Food data is stored and loaded per user account.

  • Daily food reminders

    Local notifications at 9:00 AM, 3:00 PM, and 9:00 PM.

  • Monthly food summaries

    Meal totals for the month, split into Morning, Afternoon, and Night.

  • Google Sheets + Apps Script API

    Google Sheets holds the data. A Google Apps Script web app serves it as a JSON API.

In progress

  • Admin flow

    Admin dashboard, user list, and user detail screens are built. They currently use sample data and are not yet connected to the backend.
